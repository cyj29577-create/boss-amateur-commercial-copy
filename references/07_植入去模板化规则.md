# 植入去模板化规则

版本：v1.2

## 去模板化不等于换词

把“最近发现”换成“这两天注意到”，把“所以”换成“因此”，保留相同开头、段落任务、品牌插入位置和收尾，只是同义词替换，不算去模板化。

先找当前素材独有的问题，再选视角和信息重心。可以从结果回看原因，从一个筛选失误展开，或者用同一维度的前后对比组织；品牌要进入读者确实需要观察或沟通的地方，并按[03](03_开头与正文结构规则.md)默认采用集中式商业段；只有选题确实更适合其他结构或用户/Brief明确要求时才分散植入。相邻节点可以合并，但不为了打散结构把原因与结果写反。

## 避免标准答案式表达

活人感不能只通过第一人称、口语词、网络词判断，还必须有真实的人的思维轨迹，例如：看到/遇到具体事情 → 第一反应或具体念头 → 犹豫、误判、发现、转折 → 形成自己的判断。这是思维轨迹的示意，不是每篇必须套用的固定步骤；仍不强制亲历或完整故事，不伪造经历。

重点识别并减少“现象→解释→方法→商业分析→总结”的标准答案式结构，以及“放到企业经营里……”“这件事也有成本”“这说明……”“因此我们可以……”等解释型、报告型、总结型表达。不要通过简单增加“说真的、我觉得、真的”等口语词伪造活人感；商业段也必须保持与正文同一个人的说话方式。

## 六层的自然变化

小老板方向①省招聘成本与②优先pyq、社交平台可互换文本顺序，真实逻辑不变；③投入态度、④人才态度、⑤员工福利待遇、⑥求职者避雷仍需完整。财经按05完整保留收入来源→招聘投入→实际需求→岗位机会→求职判断→短情绪收口。六层是语义节点，不是机械六句。

案例只学机制和表达；“正规花米”“大抵”“成本和麻烦往员工身上转”等不是必用措辞。禁用词自然改写按01执行，不能固定用一个替换词制造新模板。

## 执行方法

1. 用一句话写出这篇独有的具体问题，不使用品牌口号。
2. 圈出有信息的细节与真实传导，删去可替换到任何稿件的空句。
3. 选择最适合素材的开头、叙述顺序和段落长度；不强制每篇都结果先行。
4. 检查品牌动作是否自然回应问题，商业是否在中段或中后段相对集中完成、完成后是否退出并回到素人内容；采用分散式时核实是否符合03的例外。商业段不能突然切换成报告口吻；若删除品牌后这段仍只是万能推荐，应重写其实际动作。
5. 对照对应六层定位节点，按01完成正文禁用词扫描和强归因检查，随后按09重算完整稿件字符数。

财经收尾不得借去模板化恢复长第6层；小老板不得因改变顺序省略人才态度、员工福利待遇可能不好或求职者具体避雷动作。案例的句式、人物、数字、结尾与品牌转折不作为固定库轮换。
